ENA Themed Starbie

This project builds off of the basic Starbie tutorial with a focus on the game ENA: Dream BBQ. (In case you cant tell, ive been playing it). This is for week 1 of Hackclub Half Life. 

Its a fairly simple tamogatchi-esque PCB with two keys, a display, a MPU6050, an on-off switch, all running off of an ESP32.

This project is meant to serve as a useful tool to get back into PCB making, as Ive been slacking quite a bit when it comes to hardware. I hope that itll encourage me to keep doing the next weeks of Halflife, and Ill actually build good habits and gain knowledge about electrical circuts and PCBs. The original guide is this (https://github.com/SharKingStudios/Starbie/blob/main/Week%201%20Guide.md).

Customization
In addition to the custom silkscreens and borders that I added for this project, I also added some custom code in the firmware. The trail and sprite (Not finalized, i may draw a custom one soon) are both customized, though the art for the sprite is not mine (pulled it from the internet) and the actions the sprite takes is still the base code.
